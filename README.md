# Personal Portfolio Website

This repository contains the source code for my personal portfolio website.

The website was created to showcase my background, experience, projects, and skills in Computer Science.

## Website Structure

- `index.html` – Main/home page
- `cv.html` – CV and experience
- `projects.html` – Selected projects
- `contact.html` – Contact information
- `styles.css` – Website styling
- `images/` – Images and visual assets used throughout the website
- `CNAME` – Custom domain configuration

## Technologies Used

- HTML5
- CSS3
- GitHub Pages

## About

The portfolio provides an overview of my academic and professional background, technical skills, and selected projects, with a focus on Artificial Intelligence, Machine Learning, and Cybersecurity.
